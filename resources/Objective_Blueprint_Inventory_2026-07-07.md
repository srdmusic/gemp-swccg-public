## Method

- Seed list came from `src/gemp-swccg-cards/src/main/resources/card_blueprint_database.json`, selecting `cardCategory == OBJECTIVE`.
- Each front objective was paired with its `_BACK` blueprint and both Java source files were read.
- `Front Abbrev` is generated from the front-side objective title using all title words, so `This Deal Is Getting Worse All The Time` becomes `TDIGWATT`.
- `ObjectiveAnalyzer.java` facts were mirrored by parser-compatible extraction plus current hardcoded analyzer cases: My Lord, Invasion, I Want That Map, Endor Operations, ISB Operations, Hunt Down, and Shield Will Be Down In Moments.
- Java source wins over text if there is a disagreement. Long filter-based effects are summarized, not fully rewritten as engine predicates. The JSON sidecar keeps raw game text, source paths, effect class names, and choice text.
